# 운송 모바일 (안드로이드 설치 앱)

우편 운송 운행 기록, 운송료 계산, 차량 관리를 하는 앱입니다.
이 폴더는 APK(설치 파일)를 만드는 재료입니다. 아래 두 방법 중 하나로 APK를 만든 뒤 폰에 설치합니다.

- 지원 폰: 안드로이드 10 이상
- 기록은 폰 안에만 저장됩니다. 인터넷은 날씨를 볼 때만 씁니다.

## APK 만들기

### 방법 1. GitHub에서 만들기 (PC에 아무것도 설치하지 않음)

1. github.com 에 로그인하고 새 저장소를 만듭니다. 공개 범위는 **Private**으로 합니다.
2. "uploading an existing file"을 눌러 이 폴더 안의 **모든 파일과 폴더**(`.github` 폴더 포함)를 끌어다 놓고 Commit 합니다.
3. 저장소의 **Actions** 탭을 엽니다. "APK 만들기"가 자동으로 돌아가고 5~10분쯤 걸립니다.
4. 끝난 실행을 눌러 아래쪽 **Artifacts**의 `unsong-mobile-apk`를 내려받아 압축을 풀면 `unsong-mobile.apk`가 나옵니다.

### 방법 2. Android Studio로 만들기

1. Android Studio를 설치하고 이 폴더를 엽니다(Open). 처음에는 필요한 파일을 내려받느라 시간이 걸립니다.
2. 메뉴 Build → Build APK(s) (버전에 따라 "Generate APKs")를 누릅니다.
3. `app/build/outputs/apk/debug/app-debug.apk`가 만들어집니다.

## 폰에 설치하기

1. APK 파일을 카카오톡 "나에게 보내기", 메일, USB 등으로 폰에 옮깁니다.
2. 폰에서 파일을 누릅니다. "출처를 알 수 없는 앱 설치"를 허용하라는 안내가 나오면 허용합니다.
3. Play 프로텍트 경고가 나오면 "무시하고 설치"를 누릅니다. 스토어에 올리지 않은 앱이라 나오는 안내입니다.
4. 처음 열 때 알림 허용을 묻습니다. 기한 알림을 받으려면 허용합니다.

새 버전도 같은 방법으로 만든 APK를 그대로 설치하면 기록을 유지한 채 덮어씁니다.
(프로젝트에 들어 있는 `app/unsong.jks` 서명 열쇠가 같아야 덮어쓸 수 있으므로 이 파일을 지우거나 바꾸지 마세요.
이 열쇠가 있으면 누구나 같은 이름의 업데이트를 만들 수 있으니, 프로젝트는 믿을 수 있는 사람에게만 전달하세요.)

## 설치 앱에서 달라진 점

| 기능 | 내용 |
|---|---|
| 전화 걸기 | 연락처의 번호를 누르면 폰 전화 화면이 열립니다 |
| 폰 알림 | 검사·보험 만기·소모품 교체 시기를 아침 8시에 알림으로 알려줍니다 (30일 전, 7일 전, 하루 전, 당일) |
| 날씨 | 첫 화면과 홈에 현재 기온, 최고·최저, 강수확률을 보여줍니다. 날씨 칸을 누르면 현재 위치 기준으로 바뀝니다 (기본은 서울 광진구) |
| 지문 잠금 | 비밀번호를 등록했으면 지문이나 폰 화면 잠금으로도 열 수 있습니다. 앱을 5분 넘게 떠나 있으면 다시 잠깁니다 |
| 오프라인 저장 | 인터넷 없이 모든 기능이 동작합니다 (날씨 제외) |
| 자동 백업 | 7일마다 폰의 다운로드 폴더 안 "운송모바일"에 백업 파일을 저장합니다 |
| 캡처 자동 입력 | "운송확인서 선택" 화면 캡처의 글자를 폰 안에서 읽습니다. 인터넷이 필요 없습니다 |

### 알아둘 점

- 웹 버전에 입력해 둔 기록은 자동으로 넘어오지 않습니다. 웹 버전 통계 메뉴에서 "백업 파일 저장"을 한 뒤, 설치 앱 통계 메뉴에서 "백업 파일 불러오기"로 옮깁니다.
- 폰을 바꾸거나 앱을 지우기 전에는 통계 메뉴에서 백업 파일을 저장해 두세요.
- 캡처 글자 인식은 가끔 글자를 틀리게 읽습니다. 읽은 목록에서 노선·거리·톤수를 확인하고 저장하세요.
- 비밀번호를 잊었을 때는 지문이나 폰 화면 잠금으로 열 수 있습니다.

## 폴더 구성

- `app/src/main/assets/www/index.html` 앱 화면과 계산 전체 (단가표, 기본 노선 포함)
- `app/src/main/java/kr/unsong/mobile/MainActivity.java` 화면을 띄우고 전화·파일·위치·지문·글자 인식을 연결
- `app/src/main/java/kr/unsong/mobile/ReminderReceiver.java` 아침 알림
- `.github/workflows/build.yml` GitHub에서 APK를 만드는 설정
